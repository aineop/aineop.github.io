# aineop.github.io
This repository hosts some json files on websites I partially or completely manage, including:

- gallery.json, used for the art galleries on https://aineop.neocities.org/art and https://sribbles.nekoweb.org/gallery.html
- characters.json, used for the characters at https://sribbles.nekoweb.org/universe/characters/
- groups.json, used for groups of characters at https://sribbles.nekoweb.org/universe/characters/
